## 2024-05-18 - Optimize Image Decoding & Memoize HeroAvatar
**Learning:** Adding `decoding="async"` to `<img>` tags offloads image decoding from the main thread, unblocking the layout engine, which is particularly beneficial during complex Framer Motion animations. Additionally, purely visual components like `HeroAvatar` that have no props but contain expensive internal hooks (like Framer Motion's useMotionValue and useSpring) should be wrapped in `React.memo` to prevent unnecessary re-renders when the parent component's state or context changes.
**Action:** Aggressively utilize `decoding="async"` on all `<img>` tags (both lazy and eager loaded) to optimize performance, and proactively wrap purely visual components with no props in `React.memo` to prevent unnecessary re-renders triggered by parent component context or state changes.
