## 2025-03-09 - Async Image Decoding & Telemetry Deferral
**Learning:** Large images during initial mount and route transitions were blocking the main thread, causing minor jank in Framer Motion animations. Additionally, non-critical telemetry (gathering user agent, resolving locations, and hitting external APIs) was running synchronously in the event handlers of interaction events (like clicks and tab navigations), artificially extending the interaction-to-next-paint latency.
**Action:** Always add `decoding="async"` to `<img>` elements when prioritizing smooth animations in an SPA. Wrap non-critical, synchronous operations (such as telemetry, logging, and heavy string manipulations) inside `requestIdleCallback` (or a `setTimeout` fallback) to execute them during the browser's idle periods, preventing them from blocking user interactions and rendering updates.
