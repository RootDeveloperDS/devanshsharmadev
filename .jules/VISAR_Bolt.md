## 2025-05-18 - VISAR Bolt Optimizations
**Learning:** Adding `decoding="async"` to standard `<img>` tags offloads image decoding from the browser's main thread. This is crucial for avoiding frame drops and layout blocking, especially when complex CSS and Framer Motion animations are running concurrently on the page. Furthermore, executing telemetry tracking directly in interaction handlers (like onClick) can block the main thread and add latency to navigation or UI feedback. Wrapping non-essential operations like telemetry in `requestIdleCallback` defers execution until the main thread is idle, ensuring a smoother user experience.
**Action:** Always include `decoding="async"` on all `<img>` tags in future UI components unless synchronous decoding is explicitly required. Continue using `requestIdleCallback` to defer non-critical background tasks such as telemetry or analytics parsing, while always providing a `setTimeout` fallback for browsers (like Safari) that don't support `requestIdleCallback`.
