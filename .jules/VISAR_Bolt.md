## 2024-09-04 - React Memoization and Image Decoding Offloading
**Learning:** Purely visual elements in the component hierarchy receiving updates from parent contexts (e.g. `useTheme()`) might cause unneeded layout shifts or reconciliation cycles. By wrapping such standalone components inside `React.memo()`, we avoid these redundant cycles. Similarly, adding `decoding="async"` to elements like `<img>` complements lazy loading by freeing up main thread UI interactions while waiting for heavy payload processing.
**Action:** Always proactively wrap non-prop stateless/visual elements in `React.memo`, particularly headers, footers, and static components containing complex SVG graphics or canvas renderings. Ensure `decoding="async"` acts as a parallel standard to `loading="lazy"`.
