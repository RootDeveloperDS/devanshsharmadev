## 2024-05-18 - Semantic HTML Refactor for Nesting Interactive Elements\n**Learning:** Interactive elements nested inside anchor links (e.g., a button inside an `<a>` tag) violate HTML accessibility semantics and can cause cross-action bugs during screen reader or keyboard navigation.\n**Action:** Use a container `<div>` with sibling `<a>` and `<button>` elements styled to maintain the visual group, preserving structural integrity without losing design fidelity.
