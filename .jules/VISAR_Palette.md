## 2024-03-22 - Interaction Feedback for Links
**Learning:** Adding subtle tactile feedback (`active:scale-95`) to standard text or icon links significantly improves the premium feel of the UI. When elements like Github and Live Demo links are simple strings, they lack the click-weight of buttons unless explicitly styled.
**Action:** When evaluating clickable UI elements for UX polish, explicitly check if they respond visually to a user's press event, and add standard `active:scale-95` to anchor tags to mimic button behaviour.
