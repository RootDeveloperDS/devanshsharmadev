## 2024-03-24 - HSL Shadow Variables & Link Transform Animations
**Learning:** Hardcoding `rgba(var(--primary-rgb), alpha)` for shadows breaks when CSS variables are defined using `hsl()`, leading to invalid CSS properties that fail to render shadows. Additionally, applying hover animations that modify margins or gaps on layout containers (like `gap-3` on hover) causes disruptive layout shifts and text jumping.
**Action:** Always wrap HSL CSS variables with the `hsl()` function when building arbitrary Tailwind shadow values (e.g., `shadow-[0_0_15px_hsl(var(--primary)/0.2)]`). To provide smooth visual feedback on links without causing layout shifts, apply the Tailwind `group` class to the parent `<a>` tag and use `group-hover:translate-x-1` combined with `transition-transform` on the child icon elements. Finally, ensure interactive elements (like buttons and links) utilize `active:scale-95` to provide a subtle, premium tactile response.
