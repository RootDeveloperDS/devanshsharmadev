## 2024-05-18 - HSL Color Parsing and Tactile Feedback Improvements
**Learning:** When generating arbitrary Tailwind box-shadows using custom CSS variables (like `--primary` which resolves to HSL coordinates), utilizing `rgba()` wrapper is invalid unless standard RGB variables are supplied. Construct the arbitrary value explicitly with `hsl()` format (e.g., `shadow-[0_0_15px_hsl(var(--primary)/0.15)]`) to properly parse opacity values and ensure the intended premium glowing shadow effect works flawlessly. Moreover, subtle active scale effects significantly enhance interactive elements.
**Action:** Always construct arbitrary tailwind shadow colors with `hsl()` wrappers when working with HSL CSS variables, and apply `active:scale-95 transition-all` to clickable elements to ensure a premium interactive feel throughout the codebase without adding complex animation logic.
