## 2025-02-23 - Restoring Visual Polish with HSL and Tactile Feedback
**Learning:** Tailwind Arbitrary Values with CSS Variables
When defining arbitrary box shadow values in Tailwind that reference CSS variables defining HSL components (like `--primary` in this project which corresponds to HSL values), you must use the `hsl()` function explicitly instead of `rgba()` with `-rgb` suffixes, as the `-rgb` variables may not exist, which causes the shadow to break. Additionally, applying consistent tactile feedback across interactive elements like navigation buttons significantly elevates the perceived quality of the interface.
**Action:** When working on similar VISAR codebase shadow values, I will check if the css variable uses HSL values and format the arbitrary values properly (e.g. `hsl(var(--primary)/0.15)` instead of `rgba(var(--primary-rgb),0.1)`). For tactile interactions, I will systematically combine `active:scale-95` with `transition-all duration-200` to create a snappy, premium feel without layout jumping.
