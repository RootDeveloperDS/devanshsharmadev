## 2026-08-16 - Code Splitting Command Palette\n**Learning:** The CommandPalette component imports large dependencies (like cmdk) and rendering it eagerly impacts the initial bundle size. By moving the global Cmd+K event listener up to the parent and wrapping the component in a lazy/Suspense boundary, we significantly reduce the JS parsing/evaluation time for first-time visitors without losing global shortcut functionality.\n**Action:** Use conditional lazy loading tied to high-intent actions (like keyboard shortcuts or hover events) for heavy interactive modals.
